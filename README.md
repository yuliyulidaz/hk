# 홍콩 3박 4일 — 여행 페이지

GitHub Pages로 서빙되는 단일 파일 페이지입니다. `index.html` 하나가 전부이고, 이미지 파일(`mtr-map.jpg`, `tram-west.jpg`, `tram-east.jpg`)만 따로 있습니다.
공개 주소: https://yuliyulidaz.github.io/hk/

## 정산 탭 기록 방법 (AI 어시스턴트용 안내)

여행 중 나나가 영수증을 보여주면서 "정산에 올려줘"라고 하면, `index.html` 안의 `const MONEY = { ... }` 블록에 한 줄씩 추가하고 커밋·푸시하면 됩니다. 페이지의 다른 부분은 건드리지 않습니다.

### 위치
`index.html`에서 `const MONEY = {` 를 찾으세요. `items: [ ... ]` 배열 안에 객체를 추가합니다. 배열 맨 끝에 붙여도 되고 날짜 순서는 상관없습니다(페이지가 Day별로 묶어서 보여줍니다).

### 한 건의 형식
```js
{ day: 2, what: "침차이키 점심", hkd: 110, cat: "식비", who: "공동" },
```
- `day` — 숫자 1~4. Day 1 = 11/17(화), Day 2 = 11/18(수), Day 3 = 11/19(목), Day 4 = 11/20(금)
- `what` — 가게 이름 + 뭘 샀는지 짧게. 영수증의 가게명을 쓰고, 뭔지 알면 덧붙임 (예: "록이 딤섬 저녁", "세븐일레븐 물·간식")
- `hkd` — 홍콩달러 금액, 숫자만. 영수증 합계 기준. 소수점 있으면 그대로 (예: 48.5)
- `cat` — 다음 여섯 개 중 하나만: `"식비"` `"교통"` `"관광"` `"쇼핑"` `"숙박"` `"기타"`
- `who` — **가장 중요.** 다음 셋 중 하나:
  - `"공동"` — 둘이 같이 쓴 것 (식사, 교통, 입장료 등). 나나가 따로 말하지 않으면 이것
  - `"라라"` — 라라(친구) 개인 것. 나나가 "라라 거"라고 하면
  - `"나나"` — 나나 개인 것. 나나가 "내 거"라고 하면
- `note` — 선택. 메모가 필요할 때만 (예: `note: "현금"`)

한 영수증에 공동과 개인이 섞여 있으면 두 줄로 나눠 적습니다. 영수증이 없는 지출(옥토퍼스 충전, 노점 현금)도 나나가 말로 알려주면 같은 형식으로 적습니다.

### 환율
`rate: 178` 은 1 HKD당 원화입니다. 기록하는 날 환율로 바꿔도 되고, 그대로 둬도 됩니다. 나나가 환율을 말하면 그 값으로.

### 샘플 지우기
처음 실제 기록을 넣을 때, `items` 안에 들어 있는 샘플 8건(옥토퍼스 카드, 록이 딤섬, 세븐일레븐, 와록 빙실, 침차이키, 피크트램, PMQ 엽서, 약국 립밤)은 모두 지우고 시작하세요. 실제와 섞이면 안 됩니다.

### 커밋·푸시
- 브랜치 `main`에 바로 커밋합니다. 커밋 메시지 예: `정산: Day 2 지출 3건 추가`
- 푸시 후 1~2분이면 페이지에 반영됩니다.
- 수정 전에 `git pull`로 최신 상태를 받으세요.

### 주의
- 이 파일은 HTML 안에 JavaScript가 들어 있습니다. 따옴표(`"`)가 가게 이름에 들어가면 `\"`로 이스케이프하거나 작은따옴표를 쓰세요.
- 각 객체 뒤의 쉼표를 빠뜨리지 마세요. 마지막 항목 뒤 쉼표는 있어도 됩니다.
- 가능하면 커밋 전에 `<script>` 부분을 `node --check`로 문법 확인하세요. 문법 오류가 나면 페이지 전체가 하얗게 뜹니다.
- `MONEY` 블록 밖(일정 `TRIP`, 광둥어 `PHRASES`, CSS 등)은 수정하지 마세요. 일정 변경 요청이 오면 `TRIP.days` 안의 항목 형식 주석을 참고해 같은 방식으로 수정할 수 있지만, 정산이 주 임무입니다.
